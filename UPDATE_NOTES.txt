     * 1-Click "APPROVE & CREDIT": Atomically credits the player's wallet and updates status to success.
     * "REJECT" button with reason logging.

C. FORGOT PASSWORD & EMAIL DELIVERY SYSTEM:
   - Real Email Sending: Configured Django SMTP mail delivery with HTML email templates.
   - Branded Email Template: WinPlay dark/neon gradient styled HTML template with
     a large, easy-to-read 6-digit OTP code box, expiration notices, and security guidelines.
   - Environment Configuration (.env & .env.example):
     Django now automatically loads backend/.env. Supports Gmail App Passwords and custom SMTP.
   - Instant Local Testing Helper:

   - Account Existence Feedback: Returns clear feedback if an entered email does not exist.

D. VIRTUAL WALLET & TRANSACTION LEDGER:
   - Backend Models:
     * Wallet: Linked 1-to-1 with User. Tracks real-time balance (Decimal), currency (INR),
       and lock status. Thread-safe atomic credit() and debit() methods.
     * Transaction: Immutable audit log for every balance movement (deposit, withdrawal,
       game_bet, game_win, bonus, refund) with balance_after and reference IDs.
   - ₹100 Welcome Bonus: Automatically created whenever a new user signs up or through
     the seed command for existing users.
   - Wallet Endpoints (apps/virtual_wallet/):
     * GET  /api/wallet/              -> Fetches current balance, currency, and admin WhatsApp.
     * POST /api/wallet/deposit/      -> Add funds (supports UPI / Demo deposit).
     * POST /api/wallet/deposit/whatsapp/ -> Generates pending WhatsApp deposit request & link.
     * POST /api/wallet/withdraw/     -> Withdraw funds with balance validation & UPI ID.
     * GET  /api/wallet/transactions/ -> Paginated list of recent transactions.
     * GET  /api/wallet/admin/deposits/ -> Admin view of all deposit requests.
     * POST /api/wallet/admin/deposits/<id>/approve/ -> Admin approve & credit wallet.
     * POST /api/wallet/admin/deposits/<id>/reject/  -> Admin reject deposit.
   - Flutter Wallet Screen:
     * High-roller neon purple/gold gradient balance card.
     * Interactive Add Cash modal with WhatsApp Deposit & Instant Demo tabs.
     * Interactive Withdraw modal with balance verification and UPI input.
     * Real-time Transaction History list with color-coded badges (+ for wins/deposits, - for bets/withdrawals).

E. INTERACTIVE MINES ARCADE GAME:
   - Backend Game Engine (apps/games/):
     * MinesGameSession model: Tracks active game, bet amount, mine count (1-24),
       hidden mine locations (0-24 grid), revealed safe tiles, multiplier, payout, status.
     * Provably Fair Multiplier: Implemented mathematical formula in mines_logic.py:
       M = (1 - house_edge) * Product((25 - i) / (safe_total - i))
     * Endpoints:
       - POST /api/games/mines/start/   -> Debits bet from wallet, generates mine layout.
       - POST /api/games/mines/reveal/  -> Reveals tile (Diamond or Bomb), updates multiplier.
       - POST /api/games/mines/cashout/ -> Credits winnings to wallet instantly.
       - GET  /api/games/mines/active/  -> Resumes active game if user reloads.
   - Flutter Mines Screen:
     * Dark cyber arcade 5x5 grid (25 tiles) with smooth flip animations.
     * Customizable Bet Amount (₹10, ₹20, ₹50, ₹100, ₹500, or custom).
     * Customizable Mine Count (1, 3, 5, 10, 20 mines).
     * Live Multiplier & Next Tile Multiplier indicator.
     * Glowing Cashout button showing real-time payout (e.g., CASHOUT ₹45.60 (2.28x)).
     * Victory & Busted popup dialogs with instant wallet balance synchronization.
     * Offline simulation fallback mode if backend server is unreachable.

3. HOW TO CONFIGURE SUPABASE POSTGRESQL
--------------------------------------------------------------------------------

1. Open `backend/.env`
2. Replace `[YOUR-PASSWORD]` in `DATABASE_URL` with your actual Supabase database password:
   DATABASE_URL=postgresql://postgres.zcslpyqbusbdsggrdtma:YourActualPasswordHere@aws-0-ap-northeast-1.pooler.supabase.com:5432/postgres
3. In terminal, run migrations directly to Supabase:
   cd backend
   python manage.py migrate
   python manage.py seed_games
   python manage.py createsuperuser

All player accounts, wallets, transactions, games, and admin data will now reside directly in your Supabase database!

   git push -u origin main

(Note: Sensitive secrets like backend/.env and local sqlite databases are strictly ignored by .gitignore to keep your repo secure).
